# Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `Alt+Shift+O` | Load sample project |
| `Alt+Shift+G` | Generate section |
| `Alt+Shift+C` | Clear section output |
| `Alt+Shift+H` | Hatch patterns on or off |
| `Alt+Shift+K` | Keyboard shortcuts help |
| `Alt+Shift+S` | Getting started help |

On macOS, Alt is the **Option** key. Shortcuts are ignored while you type in a text field. Browser shortcuts such as Ctrl+G (find next), Ctrl+H (history) and F1 (browser help) are left alone.

Turn shortcuts off with **View → Keyboard shortcuts** if they clash with your browser, screen reader or keyboard layout. The setting lasts for the session.

## Menus from the keyboard

Tab to **File**, **Edit**, **View** or **Help**, press Enter or Space to open, use the arrow keys to move, Enter to choose and Esc to close. After a menu action or closing a help dialog, focus returns to the menu you used.

**View** items show their state, for example **Hatch patterns: on**. Items marked **(set by output style)** follow the sidebar **Output style** and cannot be changed from the menu.

> In-app **Help → Keyboard shortcuts** is built from `app_menubar.SHORTCUTS` so the dialog cannot drift from the shortcut table. Keep this file’s key column in sync when adding shortcuts.
